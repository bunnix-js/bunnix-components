# Release 0.11.6

Target package: @bunnix/components@0.11.6. New `quaternary` Button variant sharing the `tertiary` transparent base with a transparent-blend hover built from design tokens (`color-mix(in srgb, var(--color-fg-primary) 15%, transparent)` with a `bg-primary-dimmed` fallback), replacing the unreleased `flat` experiment that relied on the system `Highlight` color. Tertiary styling is unchanged; omitting `variant` still renders `primary`. Also includes the restructured Button playground (base, disabled, variants with wrapping grid, icon showcases) and a rewritten Button doc with the correct variant vocabulary. The `flat` name never reached the npm registry, so its removal is not a breaking change.
